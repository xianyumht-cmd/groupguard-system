# GroupGuard 功能测试核查表

生成时间：2026-06-21

本文档是内部测试与维护用，不面向普通群用户。用户手册只保留用户和群管理员需要知道的指令；本清单用于逐项核查插件功能、NapCat/OneBot API 依赖、实机测试结果和风险建议。

## 参考范围

- NapCat 官方文档入口：https://napneko.github.io/guide/napcat
- 插件命令注册：`src/commands/modules/*.ts`
- 插件实际处理：`src/services/*.ts`、`src/state.ts`、`src/join_verifier.ts`
- 自动命令覆盖报告：`COMMAND_COVERAGE_REPORT.md`

> 注意：当前 `COMMAND_COVERAGE_REPORT.md` 的“处理实现”判断偏旧，很多模块化服务处理的命令会显示 `UNMATCHED`。现阶段它只用于快速列出 matcher，不直接作为功能失败结论。

## 优先实机测试顺序

1. 低风险消息链：`签到`、`我的积分`、`问答列表`、`运行状态`。
2. 长内容与合并转发：`活跃统计`、`查战绩`、`查合集`。
3. 权限边界：普通成员执行管理命令应拒绝，管理员执行应通过，主人专用命令普通管理员应拒绝。
4. 群管理动作：禁言/解禁、踢出、头衔、全体禁言。
5. 撤回链：违禁词、针对、二维码/链接屏蔽。
6. 入群链：自动审批、暗号、拒绝词、验证失败。
7. 防冻结相关：发送限流、合并转发降级、动作队列，必须在测试群做。
