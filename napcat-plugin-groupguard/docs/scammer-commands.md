# 骗子查询与举报指令

> 内部维护说明：本文件包含主人配置指令，不适合作为客户手册直接发送。客户可见用法请以 `USER_MANUAL.html` 为准，主人维护用法请以 `OWNER_MANUAL.html` 为准。

## 主人配置

| 指令 | 说明 | 示例 |
| :--- | :--- | :--- |
| `设置骗子查询接口 <URL模板>` | 覆盖当前查询接口列表。模板支持 `{qq}`、`{wechat}`、`{wx}`、`{account}`、`{identifier}`、`{type}`。插件不内置默认接口。 | `设置骗子查询接口 http://www.pianzi.lol/api/public/search?qq={qq}` |
| `添加骗子查询接口 <URL模板>` | 增加第三方查询接口，多方查询会逐个请求。 | `添加骗子查询接口 https://example.com/search?account={account}&type={type}` |
| `删除骗子查询接口 <序号或URL>` | 删除某个第三方查询接口。 | `删除骗子查询接口 1` |
| `设置骗子举报接口 <URL>` | 设置匿名举报提交接口。 | `设置骗子举报接口 http://www.pianzi.lol/api/anonymous/report` |
| `设置骗子库限制 <最大记录数> <单条证据字数> <每账号最近证据条数>` | 控制本地骗子库体积。 | `设置骗子库限制 5000 500 10` |
| `设置骗子风控 <查询同用户冷却秒> <查询群每分钟> <查询缓存秒> <举报同用户冷却秒> <举报群每分钟> <每人每日举报> <重复内容去重小时>` | 控制查询/举报频率，降低刷屏和第三方接口压力。 | `设置骗子风控 10 20 300 60 5 20 24` |
| `骗子接口状态` | 查看当前接口、本地库限制和频率保护。 | `骗子接口状态` |

## 查询与举报

| 指令 | 说明 | 示例 |
| :--- | :--- | :--- |
| `查骗子<QQ或微信>` | QQ 和微信都会查询风险举报记录；配置第三方接口后会同步多方查询，第三方命中会回写本地库。 | `查骗子123456` |
| `举报骗子<QQ或微信> <证据描述>` | 先写入本地风险库；配置第三方举报接口后会继续提交第三方，不需要图片。 | `举报骗子123456 收款后拉黑，有聊天记录` |
| `查同行<QQ或微信>` | 查询本地同行风险库，完全不依赖第三方接口。 | `查同行123456` |
| `举报同行<QQ或微信> <证据描述>` | 写入本地同行风险库，格式必须是账号后接空格再写描述。 | `举报同行123456 偷客户并私聊拉人` |

## 接口配置说明

插件默认不启用任何骗子第三方接口，需要主人手动配置。可参考：

- 查询：`设置骗子查询接口 http://www.pianzi.lol/api/public/search?qq={qq}`
- 举报：`设置骗子举报接口 http://www.pianzi.lol/api/anonymous/report`

如果第三方网站不可用，`举报骗子` 仍会保存到本地数据库，后续 `查骗子` 可以从本地库命中。`同行` 数据完全由本地库支持。

默认频率保护：
- 查询：同用户 10 秒冷却，本群每分钟 20 次，第三方查询结果缓存 300 秒。
- 举报：同用户 60 秒冷却，本群每分钟 5 次，每人每天 20 次，同账号同内容 24 小时去重。
- 查询和举报回复使用“风险举报记录”口径，不直接代表最终定性或自动处罚。

账号格式：

- QQ：5-13 位数字。
- 微信：3-64 位，必须字母开头，只允许字母、数字、下划线、横杠、点号，不允许空格。
