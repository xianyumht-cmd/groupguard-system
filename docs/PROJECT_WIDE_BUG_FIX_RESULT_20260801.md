## 3. 已完成的实际修复

### 启动与命令初始化

- OneBot 事件增加启动闸门，初始化完成后才进入业务流水线。
- 动态命令初始化由 `plugin_init()` 等待。
- 初始化失败时复位状态，后续调用能够重新执行初始化。
- connected handlers 串行等待，bot identity 刷新完成后才处理消息。

### 发送与群管动作

- 普通发送默认 `force=false`。
- 满队列拒绝新任务，不再删除最旧任务。
- 固定发送延迟正常执行。
- 自身撤回定时器在插件清理时统一取消。
- `delete_msg` 失败向上层传播。
- 动作超时后不再对同一模糊结果立即重试。
- 动作队列使用稳定并发策略。
- 入队失败保留真实错误码。
- 合并转发兜底计入熔断历史并执行自身撤回。
- 转发消息保留真实风险场景。

### 入群与黑名单

- 群级退群拉黑写入群级黑名单。
- 管理员状态查询故障与“机器人不是管理员”分开处理。
- 查询故障不再直接跳过黑名单处置和入群验证。

### 配置与 SQLite

- 业务保存失败直接抛错。
- 主 JSON 与群配置通过协调事务提交。
- 全量保存删除 SQLite 中已移除的群配置。
- 非法数字配置回退到有限默认值。
- 非法 `configVersion` 从版本 1 执行完整迁移。
- StorageAdapter 支持关闭和重新绑定数据目录。
- 损坏迁移文件中止迁移，不写完成标记。
- 损坏 SQLite 群配置直接报错，不替换为空对象。

### 群文件搬运

- 非法正则保留原值并禁用对应规则。
- 损坏状态文件先备份，搬运功能停止写入。
- 状态保存失败中断搬运流程。
- 历史消息只接受 `file_id` 强匹配。
- 自产上传记录按时间清理并限制为 2000 项。
- 自产上传去重增加机器人上传者校验。

### WebUI 与网络边界

- WebUI token 写入权限受限的持久化文件。
- 页面与 API 统一在返回内容前鉴权。
- 请求体达到限制后停止读取并返回 HTTP 413。
- 配置保存只走规范化后的严格入口。
- 查询端点只接受 localhost、明确私网 IPv4 和本地 IPv6。
- 查询响应按字节流式限长，达到上限立即取消读取。
- 未捕获同步异常执行清理并非零退出。

- 所有 Vite 构建清空输出目录。
- 双目标构建使用独立干净目录。
