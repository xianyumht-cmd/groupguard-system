# WEBUI-CONTROL-PANEL-003：统一设计系统与页面结构重构

更新时间：2026-08-05 03:05 +08:00  
状态：第一阶段代码已完成，等待完整仓库测试、浏览器实机验收和生产发布。

## 立项目标

停止继续在旧 HTML 外层叠加样式。建立可复用的控制台设计系统和统一页面信息架构，同时保持现有后端 API、字段 ID、Token、配置保存、备份和运行时刷新行为不变。

## 第一阶段实现

### 1. 独立设计系统模块

新增：

```text
onebot-plugin-groupguard/src/standalone/admin/control_panel_design.ts
```

原 `webui_theme.ts` 不再保存整套控制台实现，只保留兼容入口：

```text
applyWebUiTheme(page) -> applyControlPanelDesign(page)
```

这样后续页面组件、导航和交互统一在一个明确模块维护，不再继续向旧主题文件叠加代码。

### 2. 统一页面信息架构

所有 WebUI 页面统一为：

```text
控制台根节点
├─ 左侧导航
│  ├─ 品牌区
│  ├─ 功能搜索
│  ├─ 分组导航
│  └─ 管理提示
└─ 应用工作区
   ├─ 顶部状态栏
   ├─ 面包屑
   ├─ 页面标题与说明
   ├─ 页面级操作区
   └─ 结构化内容区
      ├─ 区块标题
      ├─ 区块内容
      └─ 区块操作栏
```

主页和以下独立页面共享相同控制台结构：

- 问答管理
- 查询与接口
- 群文件搬运
- Q群管家通道

### 3. 真实运行仪表盘

状态页摘要不再使用固定宣传文案，直接读取：

```text
GET /api/readyz
GET /api/status
GET /api/build-info
```

显示：

- 服务是否就绪
- OneBot 是否连接
- 当前机器人账号
- 运行版本和提交摘要
- 配置是否载入
- 动态命令数量

顶部“管理端在线”状态会根据 readiness 和 OneBot 连接结果切换为异常状态。

### 4. 页面级操作体验

新增：

- 未保存修改检测
- 离开页面前提醒
- 放弃修改并刷新
- 删除、取消授权、清除等危险操作二次确认
- 菜单功能搜索
- URL Hash 记录主页当前功能区
- 手机端抽屉导航
- 页面级标题、说明和操作区
- 统一区块内容区和底部操作栏

### 5. 字体与视觉规范

Windows 中文字体明确优先：

```css
"Microsoft YaHei UI",
"Microsoft YaHei"
```

不再依赖浏览器自行选择中文回退字体。

同时统一：

- 页面背景和内容表面
- 导航层级
- 表单字段
- 开关项
- 按钮等级
- 表格
- 状态标签
- 代码与 JSON 编辑区
- 日间、跟随系统、夜间主题
