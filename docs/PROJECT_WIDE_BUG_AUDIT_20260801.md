## 4. 从 Bug 台账移除的两项

### 原 GG-BUG-032

原描述为“WebSocket 发生 `error` 但不发生 `close` 时不会重连”。当前没有 Undici 运行日志、可重复测试或协议证据证明生产路径会出现“只有 error、没有 close”的事件序列，因此不计入已确认 Bug。已加入的主动恢复代码作为防御性加固保留。

### 原 GG-BUG-044

原描述为“退役字段仍残留”。残留类型、默认值和场景名称属于维护债务。现有测试没有发现退役功能可从生产主链触发，因此不计入已确认 Bug。清理代码仍然保留。
