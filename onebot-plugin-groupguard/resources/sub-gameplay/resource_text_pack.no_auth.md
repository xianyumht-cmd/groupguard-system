### 规则文案

- 领取福利命令：领取初始 1000 货币
- 雇佣命令：主人身价增加 5~10，获得大量经验，系统收取 10% 交易税
- 抢走命令：仆人 3 倍价格，主人身价增加 15~20，获得大量经验，系统收取 10% 交易税
- 赎身命令：主人获得仆人赎身的价格，系统收取 10% 交易税
- 逃跑命令：仆人 3 倍价格并减少 10~20 身价，主人获得仆人赎身价格，系统收取 10% 交易税
- 释放命令：主人释放仆人，主人增加 10~20 身价
- 仆人主动结算派遣/打工：主人获得 20~30 Gold，仆人身价 +12，仆人 EXP +100
- 仆人主动结算调教：主人 EXP +50，显示奖励 40~60，仆人身价 +1~+5，仆人 EXP +100
- 仆人主动结算安慰：主人身价 +100~+200，仆人身价 +15~+20，仆人 EXP +100
- 主人批量结算派遣/打工：主人获得 40~60 Gold，仆人身价 +2，仆人 EXP +50
- 主人批量结算调教：主人获得 100~200 EXP，仆人身价 -5~-10，仆人 EXP +50
- 主人批量结算安慰：主人身价 +20~+30，仆人身价 +5~+10，仆人 EXP +50
- 主人结算命令：主人可一键结算所有仆人，获得奖励
- 仆人结算命令：仆人可主动结算自己的事件，额外获得身价奖励
- 叫我命令：别人对自己的称呼，例如“叫我 女王”
- 赐名命令：主人为仆人起名字，例如“赐名 执事”

### 对决车辆属性模型

- H：初始耐久 / 当前 currentH。
- S：先后手 / initiative。
- A：基础伤害。
- C：特殊触发阈值和额外伤害。
- 回合：S 更高者先手；S 相等时目标方先手。
- 伤害：攻击方 currentH 减少 `A/10`，防守方 currentH 减少攻击方 `A`。
- 特效触发：closed-range `randomInt(0,1000) <= C`。
- 特效伤害：触发后防守方额外减少攻击方 `C`。
- 失败判断：`currentH < 1`。
- 待精修：图片/卡片模板布局。
